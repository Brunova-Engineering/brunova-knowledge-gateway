# Glossary

**Source:** A registered Workspace location used for governed access. **Classification:** Metadata assigned to an authorized source. **Source proposal:** A record in the durable YAML review store. **Artifact ref / sheet ref:** Identifiers used by governed spreadsheet operations. **Approval reference:** An OpenWA scope-binding and provenance value; it is not independent proof of consent.
